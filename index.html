Temporal Interpretation

The reference period shows an increase in mapped coral reef area between 2021 and 2024. The ANN projections indicate a subsequent decrease in 2027 followed by a partial increase by 2030.


These projected values represent model outputs and should therefore be interpreted separately from the reference mapping products.

Methodology

Overview of the spatial data processing workflow.

Reference Mapping

Coral reef distribution for the reference periods was obtained from Allen Coral Atlas and used as the spatial reference dataset.

Spatial Processing

Spatial datasets were processed and visualized using GIS and remote sensing approaches to characterize marine ecosystem distribution.

ANN Projection

Artificial Neural Network (ANN) modelling was applied to generate projected coral reef distribution for 2027 and 2030.

About the Project

Marine spatial analysis and visualization.

This Marine Spatial Data Portal integrates spatial, temporal, and oceanographic information to support visualization and interpretation of marine ecosystem conditions. The platform is designed as an interactive WebGIS for exploring coral reef and related marine spatial datasets.
